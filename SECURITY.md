# Security policy

## Reporting a vulnerability

Please report a suspected vulnerability through GitHub private vulnerability reporting, not in a public issue or pull request.

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Describe what you found, how to reproduce it, and what it affects.

Do not include credentials, keys, or other secrets in the report. If you found one in this repository, say where, without repeating it.

## What to expect

The report is read by the repository maintainer. A fix, if one is needed, arrives as a pull request that is reviewed like any other change.

## Scope

This repository holds the code and configuration of the project. It contains no credentials by design. Reports about a flaw that would let someone read, change, or run something they should not are in scope.
